# 常见消化系统症状门诊分流

来源：https://www.pumch.cn/department_ims/doctor/detail/4192.html
补充来源：https://wjw.beijing.gov.cn/zwgk_20040/ylws/201912/t20191216_1242338.html
主题：腹痛,反酸,恶心,呕吐,腹泻,便秘,消化不良,消化内科,消化道出血

反复反酸、消化不良、慢性或轻度腹痛、腹泻、便秘等稳定症状可优先咨询消化内科。持续呕吐伴脱水、中重度或迅速加重的腹痛、呕血或黑便、严重疼痛伴大汗、意识改变等情况需要更紧急的评估。对于胸痛同时出现恶心、呕吐和大汗者，不能简单归为消化问题，应优先排查高危胸痛。
