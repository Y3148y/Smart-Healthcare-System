# 流鼻涕与鼻塞的普通预问诊说明
来源：https://www.nhs.uk/conditions/common-cold/
补充来源：https://medlineplus.gov/ency/article/003049.htm
主题：流鼻涕、鼻塞、打喷嚏、鼻部症状、普通预问诊

流鼻涕或鼻塞属于常见鼻部症状，可能出现在不同情况中；仅凭这一项症状不能判断具体原因。预问诊可以先了解持续时间、是否伴发热或其他不适，但一般健康问题不必等待完整分诊信息才能获得简短解释。休息和补充水分是常见的一般自我照护方式，本资料不提供药物、处方或诊断建议。

如果症状持续不缓解、明显加重，或出现发热等伴随情况，宜向线下医疗人员咨询。若同时出现胸痛、严重呼吸困难、意识异常等危险信号，应立即寻求急诊帮助，不继续普通门诊推荐。
