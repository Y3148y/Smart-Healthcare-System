# 急性胸痛安全分流

来源：https://www.nhc.gov.cn/xcs/c100122/202411/81a60171b43d43ff98cc6110d65a4136.shtml
补充来源：https://www.who.int/news-room/fact-sheets/detail/heart-attack
主题：胸痛,胸闷,大汗,冷汗,呼吸困难,心肌梗死,急诊

胸痛原因很多，导诊系统不能仅凭描述诊断。初发或剧烈胸痛、压迫或紧缩感、活动后加重，尤其伴大汗、冷汗、呼吸困难、恶心呕吐、头晕或疼痛向肩背下颌放射时，应按高危信号处理并尽快呼叫急救。系统不应建议患者自行服药来替代急诊评估，也不应继续推荐普通门诊号源。
