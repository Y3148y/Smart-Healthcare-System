# 急诊预检分诊与红旗症状

来源：https://www.who.int/tools/triage
补充来源：https://wjw.beijing.gov.cn/zwgk_20040/ylws/201912/t20191216_1242338.html
主题：急诊,红旗症状,严重呼吸困难,意识障碍,休克,高危胸痛

急诊预检应优先判断病情紧急程度，而不是在线给出疾病诊断。严重呼吸困难、无法保护气道、循环灌注异常、昏睡或意识障碍、疑似急性脑卒中、类似心源性的胸痛、严重疼痛伴大汗等情况需要立即或优先救治。线上导诊发现这些信号时，应停止普通门诊号源推荐，提示拨打当地急救电话或立即前往急诊。症状轻微且生命体征稳定者才适合继续普通门诊科室匹配。
