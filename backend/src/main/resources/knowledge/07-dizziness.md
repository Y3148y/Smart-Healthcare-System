# 头晕、眩晕与恶心的导诊信息

来源：https://www.pumch.cn/detail/13499.html
补充来源：https://www.nhc.gov.cn/jkj/c100063/202109/fe3b5805d4a147c799701d641a57c75e.shtml
主题：头晕,眩晕,恶心,呕吐,神经内科,耳鼻喉科,脑卒中

头晕有不同表现，例如旋转感、站立不稳或快要晕倒；旋转性眩晕可伴恶心和呕吐。相关原因可能涉及神经科、耳鼻喉科、心内科等，单凭一句症状无法确诊。导诊应先询问开始时间、是否突然发生、持续时间、是否与转头或起身有关，以及是否出现行走不稳、单侧肢体无力、口角歪斜或说话不清。若出现突发神经功能异常、剧烈头痛、意识改变等，应立即急诊评估。没有明确危险信号但持续或反复发作时，可先由神经内科或全科进行初步评估。
