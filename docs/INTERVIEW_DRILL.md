# 面经题型、深挖追问与模拟拷打

本文件是针对当前仓库整理的**模拟题库**，不是任何公司真实面试题泄露或作者的亲历面经。题目用于检验是否真正读过代码，不能替代个人经历。[讲解模板](INTERVIEW_GUIDE.md)用于建立主线，本文件用于暴露漏洞。

## 1. 一场45分钟模拟面试

| 时间 | 环节 | 面试官要验证什么 |
| --- | --- | --- |
| 0–3分钟 | 不看稿介绍项目和本人贡献 | 定位、职责与表达是否真实 |
| 3–10分钟 | 手画完整请求链路 | 模型、Java工作流、数据库的边界 |
| 10–22分钟 | 随机选RAG或Agent连续追问 | 是否只会报技术名词 |
| 22–32分钟 | 并发/故障/隐私场景 | 能否从业务约束推导工程设计 |
| 32–40分钟 | 打开一段生产代码和一个负向测试 | 能否解释真实实现与取舍 |
| 40–45分钟 | 指标质疑、局限、反问 | 是否诚实理解证据与分母 |

练习规则：先独立回答，再看核验要点；允许说未做，不允许临时把计划说成现状。录音复盘不要包含真实患者信息或密钥。

## 2. 连续追问：Agent与安全

### 第1刀：你这不就是Workflow套壳？

**递进追问：** 哪一次选择真由模型做？模型没调工具怎么办？后端自己调了工具能算Agent完成吗？

**核验要点：** 指出 `LangChainAgentModel`、`AgentRunner`、`AgentToolGateway` 的请求/结果消息循环和后端执行边界；Agent是普通咨询分支，不能把所有Java显式调用归给模型。需要实际COMPLETED审计，不以最终回答成功替代。

**失分说法：** “类名叫Agent，所以是Agent”“有MCP接口就是模型自主选工具”。

### 第2刀：为什么不用纯Agent，或者五个医生Agent？

**递进追问：** 多Agent能否提升医学准确率？谁拥有预约权？多个模型意见冲突怎么办？

**核验要点：** 当前单个受控只读Agent，安全和写业务留在Workflow；多Agent有额外延迟、费用与协调复杂度，不能无评估就宣称更准。没有实现多模型会诊，不编造仲裁协议。

### 第3刀：胸口像被大象踩，还冒冷汗，规则能接住吗？

**递进追问：** 未命中是否正常？LLM能覆盖安全结论吗？为什么不不断加关键词？

**核验要点：** 当前该比喻存在已记录的规则覆盖缺口，见 `SafetyCoverageBoundaryTest`；未命中不证明安全。规则命中路径不依赖外部LLM不等于所有急症都能识别。新增中文临床映射应有出处、版本与回归，不做无依据词表扩张或声称已有本地BERT分类器。

### 第4刀：把“查科室”藏进Prompt能叫它挂号吗？

**递进追问：** 模型伪造patientId、tool名或医生ID呢？工具停用后旧规划还能执行吗？

**核验要点：** 服务端构造作用域与白名单，严格参数Schema，不接受模型授予身份/会话/权限；执行时重验状态，Agent没有预约写工具。提示词不是授权系统，读工具也要控制隐私与结果大小。

## 3. 连续追问：RAG工程

### 第5刀：11篇、78个chunk也叫RAG？

**递进追问：** 证明了什么？一万篇怎么做？为什么还需ES？

**核验要点：** RAG由“检索实际来源并约束回答”的链路定义，不由chunk最低数量定义；但小语料无法证明容量、泛化和医疗覆盖。使用ES是为成熟索引/查询接口及可替换适配器，不声称78片段必须靠分布式检索。扩容需重新评估存储、索引同步、过滤、容量和标签，不编造当前QPS。

### 第6刀：文档是自己写几句话加URL，怎么保证有内容？

**递进追问：** 原文放哪？清洗掉什么？是否把免责声明和导航向量化？引用怎么回原位置？

**核验要点：** 打开一篇 `knowledge/corpus` 中的中文正文、provenance与来源快照，展示章节映射及哈希；前置来源/许可登记、清洗与导入分开。线上读获准数据库正文，不实时websearch。切分记录章节、位置和文本哈希；机械清洗不等于医学知识提炼正确。

### 第7刀：420/60怎么定的，做过调参吗？

**递进追问：** token还是字符？emoji呢？跨标题重叠吗？为什么当前没有overlap？

**核验要点：** Unicode码点，不是UTF-16长度或模型Token；先章节段落、同章节打包，长段才切和重叠。当前最长207码点，实际没触发长段滑窗；不能声称420/60是消融后的最优解。完整段落不等于完整跨段医学条件。

### 第8刀：BM25倒排谁建的？

**递进追问：** ES还是自研？term→doc怎么表示？中文用IK吗？急性心肌梗死怎么分？

**核验要点：** 默认ES/Lucene，CJK分析器、title/body字段；内存postings是显式轻量实现。能说出TF、DF、IDF及长度归一；能承认CJK不保留所有医学术语，没有自定义医学词典。用实际 `_analyze`/集成测试验证，不凭直觉声称同义词必命中。

### 第9刀：你建了Qdrant collection就叫建HNSW索引？

**递进追问：** indexed_vectors_count多少？小集合走flat正常吗？换模型但同维度是否可复用？

**核验要点：** 向量写入、索引构建、实际查询策略三件事；检查collection配置与索引统计。相同维度不代表向量空间相同，模型或表示变化仍需重建并验证。合成ANN对照衡量相对exact近邻损失，不是医学相关性。

### 第10刀：RRF能写公式吗？60怎么调出来的？

**递进追问：** 为什么不直接加余弦/BM25分？无重排最终就取融合前三吗？

**核验要点：** 写出 `Σ 1/(k+rank)`，解释尺度不一致；冻结回放k=10/30/60/100未改变已报告指标，默认60并非最优证明或在线A/B结果。无重排有向量预留槽与RRF补足，最终排序并不等同纯RRF前K。重排、多样性开关、过滤与原文约束需分别解释。

### 第11刀：Recall87.88%怎么来的？Precision为何低？

**递进追问：** 每题多少相关片段？无答案题算不算？AI标AI是不是自证？

**核验要点：** 说清13开发/12验证、1950片段判断、冻结语料/配置；引用RAG原表的各分母，不能把12题都说成有相关答案。Recall与实际返回精度分开，缺省/无相关题不造分；标签是AI辅助，可能偏倚，不是人工金标或临床准确率。不能仅用“都命中标题”证明片段够好。

### 第12刀：没有rerank是不是一切都做不了？

**递进追问：** 候选漏掉了正确文档，重排能救吗？没有额度如何做实验？

**核验要点：** 先评估候选召回，再评估最终选留；重排不能创造未召回资料。冻结基线做词法/向量/融合/最终阶段比较，明确关闭状态，不静默启用付费服务，不伪造重排结果。

## 4. 连续追问：输出、流和指标

### 第13刀：原文复制100%，那你模型还有什么用？

**递进追问：** 这是幻觉消失还是绕过生成？第二轮复读怎么办？

**核验要点：** 模型用于意图、工具规划、来源/对话项选择与语义核对，医学正文故意不自由改写，这是明确产品取舍。原文忠实度和自由生成分母分开；两问重复同文是表达局限，不能称自然对话全面解决。复制能减少新增关系，但不能保证选材、条件和来源医学正确。

### 第14刀：资料真有这句话，就一定能用到这个患者？

**递进追问：** “频繁或严重发作”条件被漏掉怎么办？核对模型自己也错呢？

**核验要点：** 类型化来源计划/引用哈希、完整原段与模型语义检查分工；任一字段false或Schema不可用闭锁，不靠相似度阈值宣布被蕴含。同供应商核对可能相关性犯错，真实历史已有漏检；不能保证零幻觉或临床安全。

### 第15刀：生成完再核对，为什么说是流式？

**递进追问：** TTFT真的变快吗？断连从哪条event重放？需要Redis吗？

**核验要点：** 分清供应商SSE、阶段事件和核对后正文分段。当前不降低首段等待；断连凭轮次回读保存结果，没有Last-Event-ID队列重放。使用MySQL轮次账本与期限，不编造Redis/Redisson。

### 第16刀：总共用了多少Token、置信度95%是真的吗？

**递进追问：** 用量缺失是0吗？本轮估算是否就是账单？p95用两问算行吗？

**核验要点：** 区分实际供应商输入/输出、估算、本地非模型调用和未知；累计预算不是embedding/输出/月度账单。相似度/规则置信值不经校准不能称95%正确。两问耗时只能报告两问值，不能冒充稳定p95或提速比例。

## 5. 连续追问：数据库与交付

### 第17刀：用户双击确认、超时重试，会不会扣两次？

**递进追问：** 两个JVM呢？先查有没有再插入安全吗？最后一号怎么办？

**核验要点：** 不是check-then-act；DB唯一键占位、条件扣减和唯一回执同事务，失败回滚。确认动作/预约请求幂等身份分别解释；既有完成回执重放不授权新预约。准备不锁号，最后余号在确认时竞争，跨JVM回归不是吞吐压测。

### 第18刀：长模型调用占着事务，数据库不会爆吗？

**递进追问：** 旧请求晚到覆盖新消息呢？进程死了怎么办？

**核验要点：** 模型调用事务外，前后短事务；RUNNING归属与数据库时间期限检查，过期任务不能保存。持久轮次账本/唯一请求身份与进程内会话锁是不同保护；不能把synchronized宣传为跨实例串行。

### 第19刀：两份内容只差一个逗号，SHA不同，去重不就废了？

**递进追问：** 到底哈希正文还是请求body？做了标点标准化/SimHash吗？

**核验要点：** 精确身份用于安全重放、冲突和溯源，不负责语义相似。知识导入内容键绑定传入标题/正文，其标点/空白变化可产生新键；请求指纹另含类型化元数据，列表顺序也有影响。患者轮次哈希则在消息trim之后计算，首尾空白变化不必冲突，内部空白/标点变化可能冲突。分别说清输入与规范化，语义重复治理未实现，不随口补MinHash。

### 第20刀：MySQL发布成功但Qdrant失败，数据一致吗？

**递进追问：** 审批后撤回怎么防复活？rollback等于历史重新授权吗？

**核验要点：** 冻结快照→事务外构建/核验→授权复验/CAS切活动版本；失败不激活，撤回立即过滤，回滚也要当前授权。不是跨存储原子事务，不承诺检查后故障不存在。

### 第21刀：Docker化有什么实际证据？

**递进追问：** 多阶段吗？非root吗？ready检测模型吗？OOM健康检查会自动重启吗？

**核验要点：** 后端JRE/前端Nginx运行层、多阶段、后端非root、本机端口绑定；ready仅DB，健康标记不等于自动重启。`unless-stopped`与健康检查不同，没有K8s/OOM验收，不编造镜像体积优化比例。

### 第22刀：你说测试绿，我邮箱却说CI失败？

**递进追问：** 是测试、编译、Maven下载还是容器启动？为什么没核对提交SHA？

**核验要点：** 先绑定commit→run→job→step→根错误。本项目曾因Wrapper无法下载Maven发行包失败，当时测试未开始；本机通过与远端通过分别陈述。不能看红色stderr就认定git push失败，也不能无证据说网络抖动或重跑掩盖断言问题。

## 6. 现场练习，不要求新业务功能

| 练习 | 合格表现 |
| --- | --- |
| 解释 `MarkdownChunker` 的ID输入与码点位置 | 能说明UTF-16下标与码点转换、策略版本、哈希以及长段限制 |
| 写出RRF函数与一个两路排名例子 | rank从1、同片段身份去重、k变化，不混余弦分数 |
| 设计Schema非法输入测试 | 未知字段、重复ID、数值强转、缺项、尾随JSON都考虑 |
| 设计最后一号并发测试 | 两独立事务/JVM、就绪屏障、单成功/无负数/回执一致 |
| 按trace诊断一次拒答 | 区分没有检索词、无命中、依赖失败、选材拒绝和来源失效 |
| 演示资料撤回 | 新请求不再采用旧授权；历史保存回答处置边界说清楚 |

只读代码入口：`MarkdownChunker`、`ElasticsearchLexicalSearch`、`HybridKnowledgeCatalog`、`QdrantSemanticIndex`、`SourceAnswerPlan`、`AnswerSupportReviewer`、`PendingBookingService`、`KnowledgePublicationService`。对应测试可按类型名在 `backend/src/test/java` 搜索，不依赖本机私有日志。

## 7. 面经复盘模板

每次真实面试后由本人填写，不把公司/个人信息或现场题目在未经允许时公开。

| 项目 | 填写内容 |
| --- | --- |
| 背景 | 岗位方向、面试轮次、日期；不记录敏感个人信息 |
| 原问题 | 尽量准确复述，不事后改成自己熟悉的题 |
| 我的回答 | 区分当场说的、事后查到的与计划补充的 |
| 追问链 | 先问了什么，哪里开始答不清，面试官在验证什么 |
| 证据 | 相关类/测试/commit/指标分母；找不到就标未知 |
| 错误类型 | 概念错误 / 不懂实现 / 边界夸大 / 指标混用 / 表达失序 |
| 修正回答 | 先给结论，再说实现、证据和限制，控制在60–90秒 |
| 下一步 | 读代码、补练习或明确当前未做；不要为了面试词汇随意改业务 |

## 8. 自评分与最后底线

每题0–3分：0=概念/事实错误；1=只会术语；2=能讲实现和失败边界；3=能用代码、测试或有分母的数据证明有限结论。分数只用于练习，不是录用概率。

面试前至少做到：能画全链路、解释本人实际贡献、打开一条负向测试、说清一个指标分母、承认一个已知缺口。任何时候都不要编造临床审核、真实HIS、多Agent、自由医学生成100%、普遍低延迟、Redis事件恢复或未经实测的性能提升。
