# 项目架构

Spring Boot 单体按业务模块组织 api、application、domain、infrastructure；当前不是完整 DDD、微服务或多 Agent 编排。

## 模块

| 模块 | 职责 |
| --- | --- |
| identity | 演示登录 |
| triage | 多轮会话、危险信号、分诊版本、模型回答、人工导诊 |
| booking | 模拟预约、资格校验、幂等与原子扣号 |
| catalog | 科室、医生、模拟号源 |
| knowledge | 资料、BM25、Qdrant、融合与重排 |
| tools | 本地工具执行器与 MCP 子集入口 |
| observation | 统计与调用记录 |
| shared | API 契约、身份校验、异常和公共基础设施 |

依赖方向为 api → application → domain 接口，infrastructure 提供数据库与外部服务实现。仍有共享契约和跨模块直接依赖，不宣称完全隔离。

## 改造验收顺序与未完成项

后续以完整患者闭环验收，不以单次模型回答或小样本召回通过宣告完成：先验证运行版本并收拢未提交源码，再补最小逐轮路由/检索/生成/核对/失败诊断及敏感访问授权，复核旧语料正文、来源和适用范围，完成咨询到分诊、模拟预约或人工导诊的端到端评估，最后基于耗时数据优化性能及后台索引发布。上述仍为待完成项，不是现有功能声明。

一般追问不按每种症状增加Java分支；安全与预约权限由后端约束，模型承担自然回答和按需追问。无资料、无科室、无号源、检索故障和模型失败分别呈现；历史结果保留快照。召回相关性、引用完整性或模型核对均不能证明临床正确。完整任务清单保留在本机协作方案，不将每轮工作记录公开上传。

## 请求流程

会话服务读取当前消息与有界历史，执行风险和流程判断。危险信号由安全规则接管；普通路径显式查询知识、科室与号源，再调用模型。检索无结果时可以进入一般问答路径，不能据此生成缺乏依据的具体分诊结论。历史分诊版本保留快照。

患者流程调用进程内工具执行器，没有模型自主选择工具的循环。管理员认证的 /mcp 共用执行器，提供列表与调用子集。

## 数据一致性

MyBatis Mapper 执行 SQL，默认 H2；MySQL profile 的真实联调尚未完成。模拟预约在事务中以条件更新扣号，并使用幂等键防重复创建。前端展示的号源不等于锁号，后端须再次核验预约资格。

本人资料与聊天记录不是正式病历。没有医生工作台、真实 HIS 或医院实时人工值守。

知识正文、审批状态与来源元数据通过 KnowledgeDocumentStore 端口及 MyBatis 实现保存。检索缓存从数据库重建；新增失败回滚缓存，审批写入成功后才发布。结构化资料的许可声明未解决时不能发布；声明不是临床或法律认证。MarkdownChunker 生成章节与位置溯源，BM25和Qdrant共享批准正文；Qdrant召回校验point id与payload是否符合请求快照，不证明医学适用性。

## 生成与安全边界

2026-10-07权限边界：普通ADMIN调用观测接口通过TechnicalCallView白名单投影，不返回患者身份、工具原文或原始错误。人工导诊队列及状态更新仅返回申请编号、状态、时间和摘要访问资格，不返回患者身份、申请原因或会话编号。摘要读取另需review.authorized-subjects（环境变量HUMAN_REVIEW_AUTHORIZED_SUBJECTS）明确授予现有ADMIN认证subject；默认空列表拒绝所有摘要读取，无通配授权。授权绑定令牌subject而非显示登录输入；该部署配置不是医疗人员资质认证。读取和已认证ADMIN的拒绝访问记录写入review_access_audit，读取审计失败时不返回正文。未开放批量导出，未制定自动清理期限；不是全系统隐私合规已完成。

AnswerCallAudit将本轮回答diagnostics.traceId关联为调用ID，生成与回答核对分别记录供应商实际返回用量，核对记录ID为同trace加-review。缺失用量保持旧存储占位0，技术接口显示未知，不估算、不把部分已知用量合并成完整总量。模型失败、输出拦截或工具失败不再记作回答成功。主流程elapsed含检索及核对总等待，核对行是子阶段耗时，不能相加当完整总耗时；尚不是所有路由、工具和消息关联齐全的逐轮trace。概览工具调用数按数据库实际四类工具执行记录计数，含失败，不再用日志数乘4估算。

脱敏calls接口在原8081经HTTP验证：未认证401、患者403、管理员200，200条现有记录无敏感字段。本批当前源码JDK17、无AI_*、隔离clean test共298项（297通过、1外部跳过），前端build通过；覆盖测量用量、核对独立记录、失败终态、真实工具计数、普通管理员脱敏、显式摘要授权与审计失败不返回正文。新增改动仍需原8081重新加载后验证，不以旧运行服务代表新功能验收，不将作者测试称独立复核。

- TriageSafetyPolicy 评估危险信号，模型不能解除风险和预约闸门。
- BM25/Qdrant 阈值、RRF 和 rerank 筛选片段，相关性不代表医学适用性。
- 模型提示词把患者输入与资料声明为不可信数据。
- 输出检查拦截部分不安全表达与用药指导，不保证医学正确。
- 紧急 SAFETY_RULE 路径不等待模型，预约服务再次核验限制。
- SSE 推送处理阶段；正文完成检查后一次返回，尚非逐 token 输出。

规则与中文映射未经临床审核，未命中不能排除急症。外部调用故障必须与无资料区分，降级不能标成模型调用成功。
