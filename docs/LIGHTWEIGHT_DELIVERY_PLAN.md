- 保留 Controller → application Service → domain/store → MyBatis 的依赖方向。管理校验放 Service，不把业务塞进页面或 Controller。
- 医生/科室管理走数据接口。聊天解释由 LLM/RAG 完成，号源与风险结论仍由后端决定。
