# 故障记录：登录无响应与预问诊文本异常

- 发生日期：2026-09-25
- 影响范围：患者端登录页、智能预问诊输入与聊天气泡
- 状态：已修复并重启服务

## 1. 现象

### 登录无响应

用户填写 `zhangsan` 与密码后点击“登 录”，页面地址会变为：

```text
http://127.0.0.1:5188/?login=zhangsan
```

但界面仍停在登录页，用户感知为按钮没有响应。早期版本还可能显示“演示登录失败：请求失败”。

### 预问诊文本显示异常

用户消息和输入框出现类似以下文本，而不是中文：

```text
&#25105;&#26368;&#36817;...
```

这不是传统 UTF-8 字节乱码，而是 **HTML 数字实体被作为普通文本显示和发送**。

## 2. 根因

| 问题 | 根因 |
| --- | --- |
| 登录停留在登录页 | 登录页先后使用过跳转链接和 Vue `@submit` 提交。原生提交已经成功写入 `?login=zhangsan`，但页面状态依赖异步演示认证完成后才置为已登录；认证等待/失败时，界面没有切换。 |
| 文本实体显示 | 上游输入环境将部分中文转换为 HTML 数字实体；前端直接将该字符串提交和渲染，后端也按原字符串处理。 |
| 编码风险 | 前端此前只设置 `application/json`，后端未显式强制请求/响应 UTF-8。该项不是本次实体文本的直接根因，但会增加中文跨代理传输的风险。 |

## 3. 修复内容

### 登录链路

1. 登录页改为浏览器原生 `GET` 表单提交，账号字段通过 `login` 查询参数传递；密码字段没有 `name`，不会进入地址栏。
2. 检测到 `?login=...` 或 `?demo=...` 时，页面立即进入对应患者端/管理端，避免用户等待异步认证而误以为按钮失效。
3. 后台继续调用 `POST /api/auth/login` 获取/刷新令牌；认证短暂失败时提示“后端认证暂不可用，已进入演示模式”，不再卡死在登录页。
4. 演示入口会按 `login=admin` 进入管理员端，其他账号进入患者端。

### 文本处理与编码

1. 前端在发起分诊前使用浏览器文本解码器，将 `&#...;` 数字实体还原为字符；恢复后的文本同时用于输入框、聊天气泡和请求体。
2. 后端在同步分诊与 SSE 分诊接口再次解析数字实体，作为非浏览器客户端的兜底。
3. 前端 API 请求显式设置 `Content-Type: application/json; charset=UTF-8` 与 `Accept: application/json`。
4. Spring Boot 启用并强制使用 UTF-8 请求/响应编码：

```yaml
server.servlet.encoding:
  charset: UTF-8
  enabled: true
  force: true
  force-request: true
  force-response: true
```

## 4. 回归验证

| 校验项 | 结果 |
| --- | --- |
| `POST /api/auth/login`，账号 `zhangsan` | HTTP 200，返回 `PATIENT` |
| 通过 `5188` 前端代理发送登录请求 | HTTP 200 |
| 通过 `5188` 发送包含 `&#...;` 的分诊文本 | 后端工具轨迹回读为中文字符，不再保留实体编号 |
| 包含中文标点的分诊文本 | 成功识别为呼吸内科并返回中文结果 |
| 前端构建 | `npm run build` 通过 |
| 后端测试 | `mvn test` 通过 |

## 5. 防复发要求

1. 所有外部输入进入领域逻辑前统一做文本规范化；不能只依赖 UI 层。
2. API 客户端必须显式声明 JSON UTF-8 编码。
3. 页面入口状态不能以网络认证完成作为唯一渲染前提；应提供加载态、可重试提示或演示降级。
4. 生产系统不得沿用“任意密码可登录”的演示策略；需改为密码哈希、真实会话、刷新令牌和路由权限守卫。
5. 新增富文本、外部表单或 OCR 输入时，必须覆盖 HTML 实体、UTF-8、多字节字符、emoji 与中英文混合文本的回归用例。

## 6. 2026-09-26 认证补充修复

后续全链路检查确认，旧实现虽然签发 JWT，但业务接口没有校验签名、过期时间和角色，匿名请求也能读取管理数据。这与“登录接口返回 200”是两个不同层面的问题。

本次已增加：

1. HS256 签名、载荷格式与过期时间校验；
2. 患者接口与管理员接口的角色隔离；
3. 无 Token 返回 401、角色不符返回 403、篡改 Token 返回 401；
4. 登录只接受演示账号 `zhangsan`、`admin`，密码必须非空；
5. 对上述规则增加 MockMvc 自动化回归测试。

完整证据见 [2026-09-26 全链路回归记录](../QA_RUN_2026-09-26.md)。
